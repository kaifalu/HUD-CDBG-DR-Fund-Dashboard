# Using the CDBG-DR Fund Dashboard

## Start with a question

Use **Explore & Compare** to investigate programs and financial patterns interactively. Use **Quick Report** to produce a one-page single-area or comparison brief. Both modes use the same financial/geographic records.

## Explore & Compare

1. Leave all filters at All for a national overview. The two panels work independently.
2. Set the seven filters in order as needed: Year; Disaster Type; Grantee; Project; Activity Responsible Org; Activity Type; Activity Title. The first Year field describes the source disaster/appropriation category, not the reporting quarter.
3. Select a grantee to unlock project and activity-level choices. To unlock Activity Title, also select a project, responsible organization, or activity type. Changing an earlier filter clears conflicting downstream selections.
4. Choose a geographic level and scope. State coverage is direct. County, city/place, and urban-area matching is less complete; review Mapping coverage and match-method notes.
5. Choose one map measure and one or more funding-plot measures. Switch between Quarterly and Cumulative as appropriate. Hover over a map or plot for detail.
6. Use Panel 2 for a second selection. Keep periods, financial measures, and comparable program characteristics aligned when interpreting differences.
7. Download the aggregate CSV or map/funding-plot PNG using the buttons below the figures.

Six indicators show displayed records, unique grants, unique projects, unique activities, the net selected map measure, and mapping coverage. A record is not a project or beneficiary. Counts of distinct project titles are not an independent count of all project entities.

## Quick Report

1. Open Quick Report and choose Single-area report or Comparison report.
2. Select a geographic level, one financial measure, and cumulative or quarterly trend basis.
3. Choose Scenario A's location and reporting horizon. Presets are relative to the dataset's latest QPR quarter, not today's date. Use a custom range for exact quarter boundaries.
4. Optionally open More filters to narrow disaster/appropriation year, disaster type, grantee, project, or activity type.
5. For a comparison, configure Scenario B. Leave its shared-time option checked for the same horizon as A, or select a separate period. Both scenarios use the same financial measure and geographic level.
6. Click Generate one-page report. Re-generate after changing selections. The report includes four indicators, a map, funding trend, top-five ranking, rule-based takeaways, and interpretation notes.
7. Select Download report PNG, Print / Save as PDF, or Download report data CSV. For printing, use US Letter landscape. Allow the print window to open if the browser blocks pop-ups.

A comparison map displays B minus A. When the scenarios cover different areas, this compares selected totals, not changes within each area. Takeaways describe the selected records and do not establish causes or performance quality.

## Interpret and share responsibly

Quarterly values are net transactions. A cumulative line can fall after a correction or deobligation. Do not add cumulative values across quarters or treat spending/disbursement totals as a completion or equity score. A missing mapped record is not evidence of zero funding. City/place markers are points, not municipal boundaries.

Reports and CSV files can support monitoring, preliminary comparisons, policy briefings, classroom exercises, and follow-up research. Record the geography, financial measure, filters, time range, and data version when sharing an output. Funding data alone do not measure recovery outcomes or implementation capacity.

## Troubleshooting

- Blank page or data-loading error: use the standalone HTML or launch the multi-file site through a local HTTP server. Verify all files were deployed together.
- Old interface: remove obsolete repository files, wait for the new deployment, and refresh with Ctrl+F5 (Windows) or Shift+Reload.
- Empty results: broaden filters, use the state view, or expand the reporting period.
- Empty advanced dropdown: select its required upstream filter first.
- Map unavailable: enable WebGL/hardware acceleration or use a current browser. Charts and CSV outputs remain available.
- A download is blocked: allow downloads and pop-ups for the site, then retry.
