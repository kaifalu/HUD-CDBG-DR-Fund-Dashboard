# Package contents

- `index.html`: default GitHub Pages entry point.
- `.nojekyll`: static-site marker.
- `assets/`: application styling, JavaScript, favicon, Plotly library and license.
- `data/`: financial bootstrap, seven financial chunks, geographic assets, schema and metadata.
- `HUD-CDBG-DR-Fund-Dashboard-Hierarchical.html`: rebuilt standalone copy of the complete dashboard.
- `scripts/`: preparation, static-data build, standalone build, and validation utilities.
- `docs/`: validation outputs and new interface/report previews.
- Markdown documentation: setup, user guide, data methods, revision notes, and validation report.
- `PACKAGE_CONTENTS_SHA256.txt`: integrity hashes for all other files in this package.

No raw source CSV files, database, server runtime, original narrative data, narrative excerpt chunks, or restricted QA tables are included.
